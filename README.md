# 💎 Семейный трекер финансов и общих трат с чеками

Премиальный стеклянный трекер совместного бюджета для двоих с супругой, поддержкой Telegram Mini App (на базе **Liquid Glass UI Kit**), Telegram-ботом с распознаванием чеков и интеграцией с **Быстрыми командами на iPhone (iOS Shortcuts)**.

---

## ✨ Основные возможности

1. **Совместный учет расходов и доходов (Евгений и Супруга):**
   - Быстрый ввод трат со смартфона за 2 секунды.
   - **Приход денег (Доходы семьи):** учет зарплат, авансов, премий, подработок и кэшбэка с разбивкой по получателям.
   - **Удаление трат:** удаление конкретной покупки в один клик (кнопка 🗑) или **полное обнуление всех покупок** для старта нового периода.
   - **Настройка семьи и имен:** изменение фамилии/названия семьи, а также имен обоих супругов прямо в интерфейсе или через бот.
   - **Свой токен:** возможность задать любой собственный пароль/токен для iPhone Shortcuts.
   - Категории по умолчанию: 🛒 Продукты, 👶 Ребенок, 🚗 Машина, 📱 Подписки, ☕️ Кафе и еда, 🏠 Дом и быт, 💊 Здоровье, 🎁 Развлечения, 📦 Прочее.
   - Фильтрация по типу (*Все / Расходы / Приход денег*), по автору и по категориям.

2. **Ежемесячная аналитика и баланс 50/50:**
   - Полный финансовый поток (Cashflow): **Общий доход семьи**, **Всего расходов** и **Чистые накопления / Остаток**.
   - Мгновенная сводка: кто сколько потратил и кто сколько заработал (в рублях и в %).
   - Автоматический расчет взаиморасчетов (Fair Split): кто кому сколько должен перевести, чтобы разделить общие расходы поровну.
   - Прогресс-бар бюджета семьи на месяц.
   - Наглядная разбивка по категориям с цветовой индикацией.

3. **Telegram Бот с распознаванием чеков:**
   - **Фото кассового чека:** отправьте фото чека в бот — система распознает сумму, магазин, товары и категорию, сохранит скан чека и уведомит партнера.
   - **Текстовый ввод на естественном языке:** отправьте в чат `1500 продукты`, `Бензин 2500` или `Кофе 450` — бот сам разложит сумму, категорию и описание.
   - Кнопка **💎 Открыть трекер** прямо в меню Telegram.

4. **Интеграция с Командами на iPhone (iOS Shortcuts):**
   - Нажмите иконку на рабочем столе, виджет экрана блокировки или кнопку **Action Button** на iPhone 15/16 Pro.
   - Открывается нативное мини-окошко iOS: вводите сумму -> покупку -> готово!
   - Бот сам сортирует категорию, сохраняет в базу и отправляет push-уведомление супруге в Telegram.

5. **Дизайн Liquid Glass (стиль iOS 27):**
   - Тулбар и таб-бар мини-аппа используют оригинальный купленный набор `liquid-glass-kit` с физикой пружин, жидкой каплей, линзой `feDisplacementMap`, слиянием краев (`clip-path: path(...)`) и упругими стеклянными кнопками.
   - Полная адаптация под Telegram WebApp Safe Area (вырезы Dynamic Island, челка, нижняя полоса жестов).

## 🚀 Быстрый старт

### 1. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры:
- `BOT_TOKEN`: токен вашего бота от `@BotFather`.
- `WEBAPP_URL`: публичный URL вашего сервиса (например, адрес на сервере или туннель `https://xxxx.ngrok-free.app` при локальной разработке).
- `GEMINI_API_KEY`: *(опционально)* ключ Google Gemini для Vision-распознавания чеков. Если не указан, работает встроенный эвристический парсер чеков и QR-кодов.

### 2. Запуск приложения
Запустите сервер одной командой:
```bash
./run.sh
```
Или вручную через виртуальное окружение:
```bash
.venv/bin/python -m backend.main
```
Приложение запустится на `http://localhost:8000`.

## 🤖 Настройка Telegram Бота и Mini App в @BotFather

1. Откройте `@BotFather` в Telegram.
2. Создайте нового бота: `/newbot` -> задайте имя и юзернейм (например, `OurFamilyFinanceBot`).
3. Скопируйте полученный токен в `.env` в переменную `BOT_TOKEN`.
4. Настройте кнопку меню Web App:
   - В `@BotFather` отправьте команду `/setmenubutton`.
   - Выберите вашего бота.
   - Введите текст кнопки: `💎 Открыть трекер`.
   - Введите URL: `https://<ВАШ_ДОМЕН>/` (или ngrok url).
5. Нажмите Start в вашем боте!

## 📲 Настройка команды на iPhone (iOS Shortcuts)

Подробное руководство со скриншотами и шагами находится в файле:
👉 [shortcuts/ios_shortcuts_guide.md](file:///Users/evgeniysolilov/Downloads/finans/shortcuts/ios_shortcuts_guide.md)

**Кратко:**
1. В приложении «Команды» добавьте 2 действия **«Запросить ввод»**:
   - Первое: Число (Сумма).
   - Второе: Текст (Что купили).
2. Добавьте действие **«Получить содержимое URL»**:
   - URL: `https://<ВАШ_ДОМЕН>/api/shortcuts/add`
   - Метод: `POST`, Заголовки: `Content-Type: application/json`
   - Тело (JSON):
     - `token`: ваш персональный токен из вкладки «Семья» в приложении
     - `amount`: переменная из шага 1
     - `title`: переменная из шага 2
3. Добавьте **«Показать уведомление»**.
4. Назначьте команду на кнопку **Action Button** или виджет на экране блокировки!
